# BawaBank 🇬🇭
Live banking web app built with Python Flask — deployed on Render.

**Live Demo:** https://bawabank-2.onrender.com/

### Features
- Live balance: GHS 2500.00
- Deposit & Transfer UI
- Dark mode, fully responsive
- Deployed with Gunicorn + Flask

### Tech Stack
Python, Flask, Gunicorn, HTML/CSS, Git, Render
